# Revision_Rv2: the revised figures

| folder | figures |
|---|---|
| [`sleep/`](sleep) | Figures 1-3 and Extended Data Figs 1-7 and 9-11: d2, avalanches, branching ratio and ISI entropy across sleep and wake, SWRs, replay and barrages. Start with its [quick start](sleep/README.md#quick-start). |

Both folders have the same layout: `figure_scripts/` (the notebooks), `csv/<notebook>/` (the tables each notebook
draws) and `figure_output/` (created when the notebooks run). Notebook names follow the figures: `FigS<N>` is
Extended Data Fig. N.
